# JCS Metalúrgica — Engenharia e Precisão Absoluta

Bem-vindo ao repositório oficial da **JCS Metalúrgica**. 
Este projeto é uma plataforma web premium focada em alta performance, construída com foco na estética industrial rigorosa e interações técnicas avançadas de nível *Awwwards*.

## 🚀 Tecnologias e Stack (Precisão de Engenharia)

O sistema foi arquitetado com as tecnologias mais modernas do ecossistema web para garantir carregamento instantâneo, animações fluidas a 60fps e SEO de ponta:

- **Framework Core:** [Next.js 14](https://nextjs.org/) (App Router)
- **Linguagem:** TypeScript
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Física e Animações:** [Framer Motion](https://www.framer.com/motion/)
- **Scroll Paramétrico:** [React Lenis](https://github.com/darkroomengineering/lenis) (Smooth Scroll)
- **Micro-interações:** Web Audio API (Sintetizador Sonoro nativo para os botões)
- **Ícones:** Lucide React

## ⚙️ Features de Destaque

- **Simulador de Orçamento (HUD):** Sistema dinâmico em formato de terminal que calcula estimativas de custo baseado em dimensões e ligas metálicas com integração geográfica para frete.
- **Sequência de Inicialização (Boot Screen):** Preloader cinematográfico em console simulando a compilação de sistemas operacionais industriais.
- **Audio Feedback (UX Sonoro):** Utilização de `AudioContext` para sintetizar áudios precisos (clicks metálicos) ao interagir com áreas fundamentais do sistema, reforçando a imersão de fábrica/equipamento pesado.
- **Telemetria de Scroll:** Barra de progresso ligada a uma mola física (`useSpring`) que mapeia a posição exata da página.
- **Cursor Magnético e Customizado:** Sistema reativo que substitui o cursor nativo por elementos orgânicos responsivos baseados nos links da interface.

## 🛠️ Como Rodar Localmente

Certifique-se de que o Node.js está instalado em sua máquina e a porta `3000` está livre.

1. Clone o repositório:
```bash
git clone https://github.com/lucassantana2301-bot/jcs-METAL.git
```

2. Instale as dependências essenciais:
```bash
npm install
```

3. Inicie o sistema de desenvolvimento:
```bash
npm run dev
```

4. O sistema estará operante na porta local `http://localhost:3000`.

## 📦 Deploy para Produção

Para compilar a versão otimizada e ultra-rápida (Static & ISR) do sistema:

```bash
npm run build
npm run start
```
